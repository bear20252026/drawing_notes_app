# Notes 页面模板内容策略重构

**作者：Manus AI**  
**日期：2026-08-27**  
**目标分支：`refactor/notes-template-content-strategy`**

## 1. 改造背景

上一批已把完整可编辑页面内容收口为 `NotebookPageContent`。但交互式新建页面仍在 `NotebookViewPage` 的展示层中同时决定 A4 默认尺寸、文档标识、纸张类型、模板日期文本、文字坐标、字体大小、粗体状态和文本项标识；文本导入与克隆占位也各自构造空白文档。这使得业务模板策略无法脱离 Widget 直接测试，且新建页面的基础装配规则分散。

> 本批次将“模板对应的默认页面内容”定义为 notes 领域策略。展示层仍负责对话框、用户输入、页面加入、保存和导航；策略不持有 `BuildContext`、存储、时钟、I/O 或随机 ID 生成实现。

| 当前问题 | 根因 | 本批次的收口方式 |
|---|---|---|
| 创建模板的 140 余行规则位于 `State` extension | 模板内容被当作界面细节 | 新建纯 Dart `NotebookPageTemplateStrategy` |
| 日期、文本标识直接读取 `DateTime.now()` 和存储静态 ID | 领域规则不可预测测试 | 由调用方注入时间与 ID 委托 |
| 新建、文本导入、克隆占位各自装配空文档 | 默认纸张尺寸和文档字段无统一入口 | 策略统一创建默认与自定义尺寸文档 |
| UI 必须了解模板对象坐标、字体和内容 | 页面创建规则未形成领域契约 | 策略输出 `NotebookPageContent`，UI 仅提供页 ID、标题和模板 |

## 2. 目标契约

| 成员 | 责任 | 不负责 |
|---|---|---|
| `NotebookPageTemplateStrategy.createContent` | 创建交互式页面的画布、纸张类型与模板初始文字 | 生成页面 ID、插入笔记本、保存、导航、通知 |
| `NotebookPageTemplateStrategy.createDocument` | 创建标准或自定义尺寸的无混排文档 | 模板对话框、导入文件、PDF 渲染 |
| `NotebookPageTemplateStrategy.createTextItems` | 按模板、给定日期与 ID 委托生成初始文字 | 获取系统时间或调用持久化层 |
| `NotebookPageContent` | 承载策略生成的活动可编辑内容 | 解释模板、创建日期或生成标识 |
| `NotebookViewPage` | 把用户输入和调用方依赖传入策略，并保持保存/编辑流程 | 枚举模板文字、坐标、字体与默认页面尺寸 |

## 3. 保持的行为与兼容性

交互式创建时仍使用 `2480 × 3508` 的页面尺寸、相同的 `PageTemplate.paperType` 映射、相同的模板标题/日期文案、相同的文字坐标、大小和粗体标记。默认文档继续是固定坐标页；本批次不会把 `whiteboard` 的标签误扩展为真实无限画布行为。

策略的时间和 ID 通过参数传入。页面的真实创建路径仍传入当前时间、`StorageService.newId` 与 `NotebookStorage.newId('txt')`，因此用户可见 ID 格式和日期格式保持不变；测试则能够固定这两个输入并精确断言完整模板输出。

文本导入、PDF 导入和克隆仍保留各自的业务载荷组装：文本段落布局、PDF 底图尺寸、克隆实时解析都不是模板策略的职责。它们只复用策略的通用文档创建入口，去除无关的默认文档复制。

## 4. 验收不变量

| 不变量 | 验证方法 |
|---|---|
| 七种页面模板全部保留既有纸张映射 | 模板策略直接测试 |
| 会议、康奈尔、计划页初始文字内容与布局完全保持 | 固定时间/ID 的精确断言 |
| 空白、横线、方格、点阵、白板模板不生成文字 | 参数化直接测试 |
| 交互创建的文档尺寸和纸张类型保持 | 领域与回归测试 |
| 自定义尺寸文档供 PDF 导入复用，且不混入模板文字 | 领域测试 |
| 策略没有 Flutter Widget、I/O 或存储依赖 | 架构检查与源码审阅 |
| 页面创建、文本导入、PDF 导入和克隆流程保持其界面/保存时序 | 全量回归测试 |

## 5. 非目标

本批次不重绘模板背景，不新增模板类型，不引入模板持久化 schema，不自动迁移现有页面，也不改变 PDF/文本导入算法。后续若要支持用户自定义模板、真实无限画布或本地模板库，应建立单独的产品与存储设计。
