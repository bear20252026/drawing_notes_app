# 开源项目调研与借鉴记录（LEARNED）

> 调研对象：用户提供的 8 个笔记软件 + 7 个办公套件开源项目
> 调研目的：学习成熟产品在"笔记文字体验"上的做法，落地到本项目（绘图+笔记混合应用）
> 原则：**保持本项目现有 UI 设计不变**，只借鉴交互与功能模式

## 二、本次落地的借鉴项（已实现，UI 布局不变）

针对用户实测反馈（"字小的咪咪小""无法调整位置""功能配置差"），借鉴
Joplin/Umo Editor/AbiWord 等成熟产品的文字体验，落地 3 项：

1. **文字块字号可调**（借鉴 Umo/AbiWord 字号控件）
   - 新增文字对话框内附字号滑块（8~200，默认 28）；
   - 选中文字块后工具栏出现快捷字号滑块 + 当前值显示；
   - 双击文字块编辑时保留原字号。

2. **文字块颜色可调**（借鉴笔记软件文字样式能力）
   - 选中文字块后工具栏出现颜色圆钮，点击弹出既有色板（12 色 + HSB 自由调色）；
   - 修改即时生效并自动保存。

3. **文字块位置可拖动**（已有能力，本次修复坐标偏移后真正可用）
   - 此前"点击位置与绘制位置不一致"的坐标变换 bug 已修复（viewToCanvas/canvasToView
     与 CanvasPainter 统一为围绕画布中心的互逆模型），文字/图片块拖动现在精确跟随鼠标。
