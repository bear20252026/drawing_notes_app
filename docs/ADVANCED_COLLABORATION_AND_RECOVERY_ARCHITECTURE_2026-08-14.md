# 高级协作、同步与恢复架构差距矩阵

**日期：** 2026-08-14  
**作者：** Manus AI  
**研究基础：** Excalidraw 的加密协作中继、客户端协调、持久场景事务与恢复流程；Saber 的通用同步队列和加密 WebDAV 适配器。[1] [2] [3] [4]

## 结论

当前绘图笔记应用应优先把本地文档恢复提高到“遇到局部损坏仍能安全打开、显示可用内容、修复失效关系”的水平，再建立可观测同步队列，最后才考虑实时协作。原因是实时协作需要服务端、账户/房间鉴权、密钥分发、传输安全、冲突 UX 和跨设备测试；若现在只添加网络按钮而没有操作版本、恢复和冲突边界，会违背“功能必须真实可用”的产品要求。

> **本轮选择：** 独立实现“防御性文档恢复与绑定关系修复”。它直接改善本地文件、导入数据、异常退出后的可用性，并成为未来同步和协作接收远端数据的安全前置层。

| 机制 | 上游可验证做法 | 当前工程状态 | 风险 | 当前决策 |
|---|---|---|---|---|
| 实时房间中继 | Excalidraw 服务端仅按房间转发客户端加密负载，文档语义与解密留在客户端。[1] | 无协作服务、无房间密钥协议。 | 贸然引入会暴露数据与制造无法恢复的版本冲突。 | 暂不实现网络协作；先建立本地操作/版本基础。 |
| 远端元素协调 | Excalidraw 用元素 ID、版本、nonce、编辑状态和分数层级进行确定性协调。[2] | 无对象版本、无操作日志；单机集合快照历史正常。 | 文件时间戳无法合并同一对象的并发编辑。 | 多选/端点编辑后设计增量操作批次。 |
| 场景持久化 | Excalidraw 将加密场景快照持久化与 websocket 广播分层，写入事务中重新协调。[3] | 本地 JSON、每文档写入尾队列和 `.bak` 回退已实现。 | 外部或损坏 JSON 可使整个文档无法打开。 | 实现局部对象隔离、基本几何限制和绑定目标修复。 |
| 文件同步 | Saber 分离本地/远端映射、队列、互斥、退避与 WebDAV 适配。[4] | `DocumentRepository` 仅包含本地 CRUD。 | 缺少版本、队列、冲突副本和进度可视化。 | 后续新增独立 `DocumentSyncAdapter`，不修改画布控制器。 |
| 删除/墓碑 | Excalidraw 为协作保留删除状态并在恢复中修复无效关系；Saber 用零字节远端文件表达删除。 | 删除立即移除对象；箭头删除已安全降级。 | 未来协作中删除会被离线旧副本复活。 | 未来操作协议引入逻辑版本和墓碑；单机保持物理删除。 |
| 加密边界 | Excalidraw 与 Saber 均将加密置于传输/文件字节边界而非绘图对象内部。[1] [3] [4] | 已有 AES-GCM 与 keyfile 独立服务。 | 将加密字段混入模型会破坏渲染与历史逻辑。 | 未来同步适配器复用独立 `EncryptionService`。 |

## 防御性恢复的独立规格

当前 `DocumentCodec` 将从全局“任一对象失败即抛出”演进为两层处理。根文档结构、文档 ID 和必要顶层类型仍然严格验证；图层、笔画、形状与图片等独立可选对象则逐项尝试恢复。一个对象的格式或几何损坏不应阻断其余对象与文档元数据的恢复。

| 数据类别 | 恢复动作 | 明确不做的事 |
|---|---|---|
| 根结构/文档 ID | 根节点不是对象、没有文档对象或 ID 非法时抛出 `FormatException`。 | 不创建身份未知的“伪文档”。 |
| 图层 | 跳过无效层；保留至少一个安全默认图层；透明度限制在 0..1。 | 不从损坏笔画中猜测原始数据。 |
| 笔画 | 跳过无点、非有限坐标、非有限宽度或无法解析的笔画。 | 不使用无限/超大数值参与渲染。 |
| 形状 | 跳过重复 ID、无效坐标、非正尺寸或越出安全几何界限的形状。 | 不隐式改变有效对象的 ID 或层级。 |
| 箭头绑定 | 箭头只保留指向存在且可绑定目标的端点绑定；其他绑定解除为自由端。 | 不删除箭头或覆写其可见自由端几何。 |
| 图片 | 跳过重复 ID、空路径或无效几何图片项；不检查本地文件是否存在。 | 不在恢复路径中删除任何图片文件。 |

## 未来同步与协作的分阶段接口

| 阶段 | 新层 | 关键输入/输出 | 真实完成定义 |
|---:|---|---|---|
| S0 | `DocumentRecovery` | 编码字节 → 已验证、可渲染 `DrawingDocument` + 可诊断丢弃计数。 | 损坏对象不影响可用对象；绑定不悬挂；所有回归通过。 |
| S1 | `DocumentChangeRecord` | 文档 ID、单调递增本地版本、内容哈希、变更时间。 | 每次成功保存都可比较版本与内容，且不改变画布 API。 |
| S2 | `DocumentSyncAdapter` | 本地编码快照 ↔ 加密远端字节；队列事件与指数退避。 | 离线可编辑，恢复联网后可同步；失败可见，不阻塞输入。 |
| S3 | `ConflictResolver` | 本地/远端版本 → 保留版本或冲突副本。 | 永不静默覆盖手写内容；用户可打开、比较和删除冲突副本。 |
| S4 | `RealtimeSession` | 操作批次 ↔ 加密房间广播；光标/视口仅易失传输。 | 多人同时编辑可收敛；断线重连不丢本地操作；独立服务审计通过。 |

## 已完成的 S0 独立实现：防御性文档恢复

本轮已在 `DocumentCodec` 实现 S0 恢复边界。实现并不引入网络、协作协议或第三方同步依赖；它仅强化本地 JSON 与未来远端快照共同经过的入口。根节点、`document` 对象和安全文档 ID 保持严格校验，无法确认身份的内容不会被构造成新文档。可选对象集合则逐条恢复：无效图层/笔迹/形状/图片被隔离，可靠对象继续打开。

恢复层对画布维度、图层不透明度、笔压、笔画宽度、对象坐标、形状/图片尺寸和旋转做有限性与范围检查。它拒绝超大或无效几何，避免导入损坏文件后在 `CustomPainter`、位图缓存或导出中产生无限计算。箭头恢复时重新检查端点目标：仅指向当前文档中可绑定矩形、椭圆或菱形的端点继续保留；其余端点解除绑定并继续使用箭头已有自由端几何。

| 验收用例 | 结果 |
|---|---|
| 根节点或文档 ID 无效 | 抛出 `FormatException`，不创建身份未知文档。 |
| 单条笔画、图层、形状或图片损坏 | 局部隔离，其他有效对象仍可打开。 |
| 图层不透明度、笔压和画布尺寸越界 | 恢复为安全范围。 |
| 重复对象 ID、非正/过大尺寸、非有限几何 | 不参与文档渲染或编辑。 |
| 箭头目标缺失 | 解除对应绑定，保留另一端及自由端显示语义。 |
| 全部可选对象无效 | 恢复为一个默认空图层，而非崩溃。 |

新增 `test/document_codec_recovery_test.dart` 共 3 项回归，已与静态分析通过。此能力是未来同步/协作接收不可信远端快照时的必要安全前置条件，但它不替代冲突版本、队列或实时协作服务。
