## 已实现的真实功能闭环

### 独立、可持久化的形状对象

`PageShapeItem` 现在包含 `locked` 状态、可靠的 `copy()` 复制语义和双端端点绑定字段。旧文档没有锁定或绑定字段时按安全默认值读取，因此历史数据不会因本轮模型升级而失效。形状对象选择状态与图片对象、笔画套索选择状态分别维护，避免“选择图片却对形状执行删除”的状态串扰。

| 用户动作 | 控制器行为 | 可见结果 | 历史边界 |
|---|---|---|---|
| 点击形状 | 根据绘制层级命中并记录形状 ID | 蓝色选中边框；锁定时采用琥珀色提示 | 不创建历史记录 |
| 拖动形状 | 更新目标坐标并重新投影受影响箭头 | 目标和连接箭头同步移动 | 一次拖动为一条命令 |
| 缩放形状 | 按最小尺寸约束调整边界并重新投影 | 尺寸更新，端点仍留在正确锚点 | 一次缩放为一条命令 |
| 锁定/解锁 | 切换持久化 `locked` 字段 | 锁定状态可见且写入文档 | 一次切换为一条命令 |
| 删除目标 | 冻结箭头绝对端点、解除匹配绑定再删除 | 箭头保留视觉位置，改为自由端 | 删除及箭头降级为一条命令 |
| 取消拖动 | 还原手势前形状集合 | 不保留半途移动或缩放 | 不创建命令 |

### 双端绑定箭头的投影模型

每个箭头端点可独立保存 `ShapeEndpointBinding(targetShapeId, normalizedAnchor)`。归一化锚点为目标边界内的 0 至 1 坐标；反序列化会夹紧异常值。几何层负责可绑定目标命中、锚点创建、端点解析、单端自由回退及整体重投影；控制器只负责将用户编辑组织成原子事务。

这意味着持久化模型储存的是**关系**而非每次对象移动后的冗余端点坐标。`shapeForRendering()` 在绘制与导出路径生成投影视图，但不为了显示而回写文档。这一设计保证了跨帧渲染、撤销、导出和未来协作同步可以使用一致的关系语义，并对应 Excalidraw 将元素关系与编辑操作分离、维护绑定完整性的设计方向。[1]

| 关系状态 | 起点 | 终点 | 删除一个目标后的结果 |
|---|---|---|---|
| 双端已绑定 | 解析到起点目标锚点 | 解析到终点目标锚点 | 被删除的一端冻结为自由端，另一端仍绑定 |
| 单端已绑定 | 解析到目标锚点 | 使用自由绝对坐标 | 删除该目标后该端保留当前绝对坐标 |
| 双端自由 | 使用自由绝对坐标 | 使用自由绝对坐标 | 不受其他对象删除影响 |
| 目标 ID 异常或丢失 | 安全回退为自由坐标 | 安全回退为自由坐标 | 渲染不崩溃，不写回破坏性数据 |

### 原子化撤销/重做

`DocumentShapesSnapshotCommand` 保存整个形状集合的前后快照。它并不把“移动节点”和“更新 N 条箭头”拆为多条用户可见历史命令，因此撤销/重做不会落入半同步状态。该策略尤其适用于当前单文档本地编辑模型；在后续加入协作时，可以继续复用快照边界作为操作批次基础，并将其扩展为增量操作协议。
