## Excalidraw：核心可借鉴结论

Excalidraw 将自由绘制建模为独立元素，而非短暂的绘制命令。元素持有原始点列、压力序列、是否模拟压力及笔触选项；普通图元还统一携带位置、尺寸、角度、样式、层级、绑定、锁定、版本和删除状态。该思路适合将当前应用逐步统一为“可编辑场景元素”模型。

自由绘制的视觉核心是原始采样点与渲染几何的分离。其变量宽度路径采用压力驱动的轮廓生成，并使用经验调校的尺寸因子、细化、平滑、streamline 和缓出曲线；恒宽笔迹则采用独立几何路径，并将压力钉为 1。上游代码明确指出，命中检测、填充等边界敏感操作不能仅使用稀疏原始点，应使用同一 streamlining 规则下的平滑中心线。

| 主题 | 观察到的架构原则 | 当前项目的下一步等效实现 |
|---|---|---|
| 手写感 | 原始采样、平滑中心线、填充轮廓三层分离；压力和非压力模式独立调参 | 在 `StrokeGeometryCache` 中增加低质量实时中心线、完成态高质量中心线与轮廓缓存，并用视觉测试调校参数 |
| 图元数据 | 每个元素有通用几何、样式、版本、锁定、分组和绑定元数据 | 把形状、图片、文字、笔画逐步收敛到通用可选中元素协议，补齐锁定与分组历史 |
| 编辑器工具 | 图形、自由绘制、擦除、选区、对齐、图层、绑定、库和导出组成连续工作流 | 先补齐多选对象变换、连接线绑定、复制粘贴和模板库，再扩展流程图等低频图元 |
| 性能 | 离屏/局部缓存与交互态绘制分离 | 保留现有图层缓存，增加几何缓存质量等级与脏区策略，避免每个采样触发全量路径重算 |

## Saber：核心可借鉴结论

Saber 的手写模型将原始笔点持久化，延迟派生出低质量/高质量多边形和路径缓存。活动书写时采用简化几何，收笔后生成高质量轮廓、可选优化重复点，并将完成态路径变为平滑曲线。它还将工具的默认参数、压感开关和上次使用配置分开管理。

Saber 的高亮笔使用独立画布合成，解决重叠加深和覆盖文字的问题；这一行为已经在本项目的 `InkLayerPainter` 中实现。Saber 的激光指示器体现了更强的产品行为：笔画先在短暂停留后，按原始输入节奏从起点逐点消退，并以彩色外层和窄白色内层形成发光观感。该逻辑仅作为行为参考，后续将重新设计为本项目的临时激光工具。

| 主题 | 观察到的产品行为 | 当前项目的下一步等效实现 |
|---|---|---|
| 实时书写 | 低质量预览与高质量完成态分离，避免书写时卡顿又保证停笔后圆润 | 加入实时简化点间距阈值、收笔后精细重建与可控质量档位 |
| 压感 | 有真实压感时停用模拟压感；无压感工具采用恒宽或模拟模式 | 将现有触控笔优先策略与笔刷预设扩展为“真实/模拟/固定”三种明确笔压策略 |
| 形状识别 | 完成笔画后进行单笔识别，低置信度保持笔画 | 扩展当前矩形/椭圆保守识别，加入直线、菱形和箭头候选预览与可撤销替换 |
| 激光 | 延迟后按时间序列从笔画前端逐点消失，并以双层光效显示 | 把当前整条淡出临时高亮笔升级为独立激光工具：分段寿命、渐变尾迹、发光双描边、绝不持久化 |
| 笔记工作流 | 文件夹层级、最近文档、页面管理、PDF/图片与同步 | 在现有本地优先多文档存储上，优先完成页面缩略图、文档搜索、目录组织和安全同步设计 |

## 本轮深度研究后的优先级

1. **手写渲染 v2：** 采样节流、实时低质量轮廓、完成态高质量轮廓、真实压感/模拟压感明确分流及可视化性能基准。
2. **激光工具 v2：** 从普通临时高亮笔中拆出独立工具，实现逐段退场、尾迹、双层发光，并保证不会写入工程。
3. **对象编辑器：** 通用对象选择、锁定、分组、复制粘贴、对齐分布、连接线绑定和图形模板库。
4. **笔记工作流：** 文档树、最近列表、全局搜索、页面缩略图、PDF 页面管理、离线优先同步设计。
5. **协作与端到端加密：** 必须在本地数据和冲突解决稳定后单独规划；不能作为纯 UI 图标抢跑。

## Saber 专题深化补充

### 模块与依赖边界

对 `saber-notes/saber` 提交 `f534abb` 的 `pubspec.yaml` 审计表明，其应用采用 Flutter/Dart，并组合 `perfect_freehand`、`pdfrx`、PDF 导出、富文本、Nextcloud、抽象同步框架、安全存储、AES/crypto、后台任务、剪贴板、图像处理与 BSON 等模块。这个依赖面说明 Saber 是完整笔记产品而非单一画板；但其 GPL-3.0 源码不得移植到本项目。

### 画布渲染与手写表现

Saber 的画布渲染器具有明确图层顺序：同色高亮笔分组离屏合成，非高亮笔、临时激光、活动笔画、检测到的形状候选、选区与页码提示依次绘制。深色阅读通过渲染时反相选择 `darken` / `lighten` 混合策略，而不修改原始笔画数据。铅笔在高质量条件下使用专用 shader，缩小时退化到低成本颜色混合，说明“视觉保真与滚动性能”需要按缩放等级切换。

### 页面模型与资料管理

Saber 的 `EditorPage` 将页面尺寸、持久化笔画、临时激光、图片、富文本、背景图和原生资源缓存拆开管理。临时激光不进入持久化笔画列表；页面预览高度由背景、笔画、图片和文字的实际内容范围推导。页面按工具与高亮笔颜色排序，以保障高亮笔合成与绘制顺序稳定。资源释放明确包含 shader、图片和富文本控制器。

| 可独立采纳的原则 | 当前项目对应状态 | 后续独立实现方向 |
|---|---|---|
| 渲染顺序固定且临时工具不持久化 | 已实现临时高亮笔和独立激光工具 | 补充统一的渲染阶段枚举与视觉回归截图 |
| 同色高亮分组离屏合成 | 已实现 `InkLayerPainter` | 在深色阅读模式中改为渲染变换，而非改写文档颜色 |
| 缩放等级决定笔刷质量 | 现有实时采样与收笔质量分离 | 加入基于视口缩放的铅笔纹理/低成本预览质量档位 |
| 页面内容边界用于预览与导出 | 独立画布已覆盖笔画、图片和形状范围 | 使分页笔记缩略图、导出和页面内容高度共用边界计算 |
| 原生资源可释放 | 独立文档图片缓存已 dispose | 对页面缩略图/图片缓存增加生命周期测试 |

### 形状笔与选择交互深化

Saber 把形状识别放入显式的“形状笔”工具，而不是对全部普通笔画强制转换。书写期间通过可配置延迟触发识别，先显示半透明候选预览；收笔时才决定将原始笔画保留，或转为直线、矩形、圆、三角形、星形等可绘制几何。这种设计降低了日常书写被误识别为图形的风险。

其套索选择将封闭路径与笔画低质量轮廓做点比例命中，门槛为 70%；图片则使用 5×5 网格采样判断覆盖比例。此方案强调“大部分被圈住”而不是边界相交即选中。当前项目已增强为包含笔画边界交叉时也可选中，更适合稀疏长笔画；后续可在选项中提供“接触即选 / 大部分包围”两个行为，而非修改默认语义。

| Saber 行为观察 | 独立重写建议 | 当前状态 |
|---|---|---|
| 显式形状笔与去抖候选预览 | 为当前手绘形状识别增加用户可选的“形状笔 / 自动识别”模式；绘制中显示候选虚线 | 当前收笔后保守转矩形、椭圆、菱形与多采样直线，尚无候选预览 |
| 识别失败返回原始笔画 | 所有转换均必须是单次可撤销替换 | 已实现 |
| 套索按覆盖比例筛选 | 添加可配置严格包围模式以适应精准笔记选择 | 当前为边界交叉友好模式，尚无严格模式 |
| 图片用网格采样命中 | 混排对象选择采用对象类别对应的稳健命中算法 | 独立画布图片的选择变换仍为后续高优先级缺口 |

## Saber PDF、深色阅读与同步专题结论

### PDF 与图片资源

Saber 将一个 PDF 作为可复用二进制资源，并以“PDF 资源标识 + 页码 + 目标矩形”创建每个页面的 PDF 图像元素。PDF 文档通过文件路径或内联字节作缓存键，采用渐进加载；图像元素首次可见时才加载，离开可见区域后延迟约五秒释放运行时资源。PDF/图片的反相是元素属性和渲染参数，不改写原始 PDF 或图片字节。

当前项目采用“逐页渲染为 PNG、每页生成独立笔记页”的稳定优先策略，已经形成可保存的批注闭环。若升级为原始 PDF 共享资源模式，应先设计跨页资源索引、原生资源池上限、可见性加载、文件删除引用计数和 Windows/Android PDFium 测试；不能仅把大 PDF 字节重复存入每个页面。

### 非破坏性深色阅读

Saber 将页面背景、笔画、PDF/图片分别依据 `invert` 渲染，并为图片提供可反相标记。核心原则是：**阅读模式只是显示变换，原始页面颜色、图片字节、导出和同步数据必须保持不变。** 当前项目若实现此功能，应在 `CanvasPainter` 或页面显示容器添加可关闭的阅读滤镜，并为纸张模板、图片、PDF 底图和高亮笔做视觉回归；禁止直接修改文档中的颜色字段。

### 加密同步边界

Saber 的设计将传输账户凭据与笔记加密密码分离。远端配置保存了由用户加密密码封装的数据密钥和 IV，文件内容以及远端路径均在上传前加密/混淆；同步以本地文件为基础扫描变化，按修改时间选择赢家，显式处理远程删除、重试、重新同步和后台加解密。其实现细节受 GPL-3.0 约束，不能复用。

本项目已有本地 AES-GCM、恢复密钥、原子写入、写入队列与备份恢复。若增加同步，安全路线应为：独立定义版本化加密信封；每个文档使用随机数据密钥；使用用户凭据或恢复密钥封装数据密钥；以操作/版本向量处理冲突而非单纯“最后修改时间”；上传加密内容及最小化元数据；并对网络中断、并发编辑、删除墓碑、密钥轮换和恢复测试建立自动化覆盖。

| Saber 行为观察 | 本项目当前状态 | 独立实现前置条件 |
|---|---|---|
| 原始 PDF 跨页缓存和渐进加载 | PNG 底图逐页导入已闭环 | 资源池、引用计数、原生 PDFium 真机基准 |
| 图片/PDF 阅读时反相而不改写资源 | 尚未提供文档内容深色反相 | 显示层滤镜、元素可反相标记和导出不变性测试 |
| 可见资源延迟卸载 | 文档图片惰性解码并在控制器销毁时释放 | 可见性驱动缓存和内存上限策略 |
| 账户与笔记加密密码分离 | 本地密码 / 恢复密钥基础已存在 | 明确密钥层级、加密信封格式、密钥轮换与丢失风险提示 |

## 已独立落地：非破坏性深色阅读

基于 Saber 对“阅读显示与原始页面数据分离”的行为原则，本项目新增编辑器顶栏的**深色阅读（仅显示）**开关。该功能以 Rec.709 保亮度颜色矩阵包裹画布视觉层、网格、形状草稿及笔记混排覆盖层；它不写入 `DrawingDocument`、不变更图片或 PDF 文件、也不进入 PNG/PDF/SVG/JSON 导出路径。组件测试已验证开关切换前后文档 JSON 完全一致。

当前版本采取“整个页面视觉层反相”的稳健最小实现；后续可进一步为图片/PDF 增加单独的 `invertible` 元数据、让用户选择是否反相外部资料，并为导出不变性、PDF 真机渲染和颜色可读性建立截图回归。
