# Excalidraw / Saber 源码级差距与独立实施矩阵

**日期：** 2026-08-14  
**作者：** Manus AI  
**方法：** 本矩阵基于本轮对 Excalidraw 的绑定、拖动、变换和历史模块，以及 Saber 的笔迹、画布、页面、导出和文件管理模块的源码阅读；结论同时与当前 Flutter 工程实际模块逐项比对。所有建议均为独立重写，不复制 Saber GPL-3.0 源码。[1] [2]

## 总体判断

当前工程已经越过“只有工具图标”的初级阶段：它有真实的压感输入归一化、双质量笔迹点列、完整笔画轮廓渲染、橡皮擦两种语义、规则形状创建、形状/图片对象编辑、箭头锚点投影、PDF 批注、缩略图和崩溃备份。尤其是刚完成的单形状变换与绑定箭头事务，已具备专业关系图编辑器的正确基础。

与 Excalidraw / Saber 的差距已从“功能是否存在”转为**对象关系不变量、多对象事务、资产生命周期、长文档渲染预算和跨输入导航物理**。下一阶段不应堆叠图标，而应按以下依赖顺序补齐底层可验证能力：先扩展多对象选择与原子变换，再增加端点直接编辑与关系索引，然后补资产引用清理和显示缓存预算。

## 关键事实与设计取舍

### 1. 关系图不变量需要从“单向绑定”演进为“可核验的关系表”

当前 `ShapeEndpointBinding` 储存目标 ID 和归一化锚点，优点是文档恢复、缩放与渲染投影都稳定。它尚未储存目标对象的反向连接线清单；当前需要通过扫描全部形状找出受影响箭头。对于目前的轻量画布这是可接受的，但当引入多选、分组、自动布局或数百对象时，扫描与关系错误排查会变得脆弱。

Excalidraw 的关键可学习原则不是具体类型定义，而是维护双向一致性：写入端点时同步登记目标的绑定关系；解绑或删除时同步移除，且目标/箭头任何一方改变都能检查另一方是否保持一致。[3] 本工程应采用独立的 `DocumentShapeRelations` 派生索引，而非直接复制上游的字段与函数。这一索引可由文档形状集合重建，因此不必马上成为风险较高的持久化格式变更。

### 2. 多选必须定义“连接线随动”与“直接编辑连接线”两条不同规则

当移动一组节点时，节点之间的箭头应保持与两端节点的绑定；节点到组外对象的箭头仅更新相应端点；当单独拖动一条已绑定箭头时，用户意图通常是脱离目标而非被系统拉回原位置。Excalidraw 的拖动逻辑通过“本轮同时变更对象集合”作出这一区分。[4]

因此，本工程下一项对象能力的最小正确闭环应是：统一选择集合、组包围盒、批量移动与缩放、锁定对象排除、单条快照命令、以及在变换中传入已选对象 ID 集合来决定箭头端点投影或解绑。群组持久化、旋转和组合对象可在该闭环稳定后再加入。

### 3. 粗笔体验的目标是“活动笔划及时，静态笔划合算”，而非永久增加采样密度

Saber 的源码将当前笔划高质量、低缩放静态笔迹稀疏化、停笔后最终平滑分开处理；并只在视觉收益高时启用更昂贵的铅笔着色器。[5] 当前工程已有 `StrokeGeometryCache`：实时预览使用 `1.5` 的间距门限，结束后从原始点列按 `0.35` 间距与压感差异保留最终点。这说明“粗笔变成大点串”的旧根因已被架构修复；下一轮应以真机笔压与帧时间实测为准，避免无证据地重写已具备的输入管线。

### 4. 文档删除与重命名必须被定义为资产事务而非文件操作

当前 `StorageService` 对同一文档串行保存、临时文件替换和备份恢复已经正确解决了 A/B 文档写入互相覆盖的核心风险。然而导入图片保存到 `document_images/` 后，删除文档只删除 JSON 与缩略图而不回收引用资产。Saber 的文件管理将主文件、资源和预览合并为移动/删除/导入的同一生命周期。[6]

本工程应新增**引用清单驱动的资产清理**：删除前先解码文档、收集其 `imageItems.filePath`、只删除仍位于应用受管图片目录内且没有其他文档引用的文件；清理失败不得阻断文档删除，但必须能在下次启动的维护任务中重试。该实现需要明确拒绝删除用户外部路径。

## 建议实施顺序与验收

| 批次 | 独立实现范围 | 核心不变量 | 自动化验收 |
|---:|---|---|---|
| A（下一项） | 多选形状/图片的统一选择集合与组移动；连接线按已选目标集重投影。 | 一个手势只形成一个历史条目；锁定对象不进入变换；组内端点不漂移。 | 叠层命中、框选、混合对象移动、锁定排除、绑定箭头多端随动、取消、撤销/重做。 |
| B | 箭头端点手柄与派生关系索引。 | 端点拖到目标即绑定；拖出即安全降级；直接移动箭头不会被旧绑定覆盖。 | 双端改绑、同目标双端、目标删除、端点拖动取消、关系索引重建、JSON 往返。 |
| C | 图片资产引用清理与维护扫描。 | 不误删外部文件；不删除被其他文档引用的资产；失败可恢复。 | 删除、共享路径、孤儿扫描、`.bak` 回退、损坏文档跳过、Windows 路径。 |
| D | 长页面渲染预算与导出队列。 | 当前笔尖不被后台任务阻塞；缓存可释放；导出视觉与画布一致。 | 快速连续笔划基准、缩放基准、页面切换、导出回归、资源释放断言。 |
