## 一、P0：material_ui 迁移最佳路线（官方升级，非等待）

### 1.1 权威事实（五源一致）
| 来源 | 关键信息 |
| --- | --- |
| 官方 3.47 博客 | 独立包 1.0；`flutter upgrade` 后 `dart fix --apply --code=migrate_design_widgets` 自动迁移；MaterialUiCompatibilityBridge 桥接 |
| 官方 code freeze 博客 | 3.44 冻结、包与 SDK 代码尽量一致 → **升级到 3.47 迁移无摩擦** |
| 官方 breaking-changes | 3.47 仅 2 项小 breaking（OpenGL ES 存储方向、semantics）——升级风险低 |
| 官方 upgrade 指南 | `flutter upgrade` 稳定通道即可；`flutter pub upgrade` 更新依赖 |
| 中文社区（掘金/技术栈） | 迁移自愿但 11 月弃用；MaterialUiCompatibilityBridge 桥接生态 |

### 1.2 最佳路线：**立即升级 Flutter 3.47 + 官方迁移**（不是等待）
理由（交叉比对结论）：
1. **3.47 breaking changes 极少**（仅 2 项小项）——升级风险低于预期，无需专项等待
2. 官方明示"迁移无摩擦"（代码冻结保证新旧一致）
3. **11 月弃用是硬期限**，早升级早摆脱依赖窗口
4. 顺带收益：Impeller 桌面默认渲染器、Widget Preview stable、Wasm 推进

**步骤**（CI 与本地同步）：
```
S1 预演：本地 flutter upgrade → 3.47（stable 通道）
S2 风险扫描：breaking-changes 2 项 + 依赖解析（flutter pub upgrade）
S3 迁移：dart fix --apply --code=migrate_design_widgets（23 个 material import）
S4 桥接：MaterialApp.builder 包 MaterialUiCompatibilityBridge（第三方旧依赖）
S5 验证：flutter analyze + 290 测试 + 视觉快照 + Impeller shader/文字一致性
S6 CI：更新 ci.yml flutter-version 3.44.9 → 3.47.x
```

## 二、P1-a：DrawingController/EditorViewModel 安全迁移 Riverpod

### 2.1 权威方案（官方 + 中文社区一致）
| 来源 | 核心 |
| --- | --- |
| riverpod.dev from_change_notifier | AsyncNotifier + build() 初始化 + **immutable state**；复杂多值用 **Dart records** 平滑过渡；select 优化 |
| 掘金《Riverpod 分层》 | 按域拆 Notifier；di providers 绑定接口；Widget 只 watch；ProviderContainer+override FakeRepo 单测；跨模块走 core 接口；SideEffect 留 UI 层 |

### 2.2 971 行大控制器安全迁移路线（渐进，不冒险）
```
阶段 A（架构准备，已部分完成）：
  - 8 part 文件已是按域拆分（history/objects/selection/render/temporary）
  - _applyNotify 薄包装已存在（extension 通知通道）→ 迁移天然低摩擦

阶段 B（分域迁移，每域独立验证）：
  B1 DrawingHistoryNotifier（history part：undo/redo/图层）→ Notifier
  B2 DrawingObjectsNotifier（objects part：元素操作）→ Notifier
  B3 DrawingSelectionNotifier（selection part）→ Notifier
  B4 核心状态（document/strokes）→ AsyncNotifier（build 加载文档）
  每域：immutable state + Dart records 承载多值；select 收窄 rebuild

阶段 C（UI 接线）：
  editor_page 系列 ConsumerWidget + ref.watch(select(...))；
  SideEffect（SnackBar/导航）留 UI 层，Notifier 不写 context

阶段 D（可测性闭环）：
  每域 ProviderContainer + override FakeRepo 单测（官方 testing 指南）；
  290 测试基线保持全绿
```

**风险控制**：每域独立提交、独立验证（analyze+测试）；DrawingController 保留为兼容层直至全部域迁完（可回滚）；EditorViewModel 同理（205 行，B 阶段后迁移）。
