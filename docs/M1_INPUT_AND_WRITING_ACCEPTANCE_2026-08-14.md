## 1. 本阶段交付范围

本阶段围绕真实书写稳定性完成了高亮笔合成、输入仲裁、双质量笔画几何与独立工具预设的闭环改造。所有实现均位于本项目代码库中；没有复制 Saber 的 GPLv3 源码。

| 能力 | 已交付实现 | 可验证结果 |
|---|---|---|
| 不叠色高亮笔 | `InkLayerPainter` 按颜色建立局部合成组，使用 `BlendMode.darken` 合成；活动预览与已提交图层共用规则 | 同色高亮笔不会因重复叠加而持续变脏，普通墨迹在高亮层之上 |
| 输入仲裁 | `EditorInputArbiter` 区分触控笔、倒置笔、手指、鼠标与多指视图手势 | 触控笔接触期间拒绝新增手掌触控；第二非手掌指针取消未提交笔画并转入缩放/旋转 |
| 误触安全回退 | `DrawingController.cancelActiveStroke()` 取消未提交笔画，不写入历史、图层或保存状态 | 双指开始缩放不会留下短促误画，也不会产生可撤销的垃圾历史项 |
| 双质量笔画几何 | `StrokeGeometryCache` 使用稀疏实时预览点列和完整原始采样的收笔精修点列 | 高频输入时降低路径复杂度；收笔持久化保留端点和压感变化并清除近似重复点 |
| 独立工具预设 | `BrushPresetStore` 使用 `shared_preferences` 保存钢笔、铅笔、高亮笔、橡皮擦各自颜色/尺寸 | 切换工具会恢复其专属设置；修改颜色或尺寸后可在下次启动恢复 |
| 铅笔入口 | 左侧工具栏增加铅笔，使用独立预设（石墨色、独立大小） | 可选择、可书写、可保存、可导出；不再只是枚举占位 |

## 3. 测试设计说明

原高亮笔测试依赖像素读取，在无头 Linux 环境会因图形后端阻塞。该测试已重构为两类稳定验证：其一验证同色高亮笔分组、普通墨迹的后绘制顺序；其二使用 `PictureRecorder` 验证渲染计划能够实际写入绘制记录器。视觉混合效果仍保留在 Windows/Android 实体设备手工验收中，避免把无头环境局限误报成产品失败。

输入仲裁测试覆盖触控笔优先和掌托拒绝、第二指转入视图手势时的未提交笔画取消、关闭手指书写时的视图手势，以及明确允许手指书写时的完整起笔/收笔流程。几何缓存测试覆盖高频输入下的预览稀疏化、收笔端点保留、近点压缩和压感转折保留。预设测试覆盖工具间隔离、JSON 往返和异常值边界保护。

## 4. Windows / Android 实体设备最终验收清单

在有压感触控笔的 Windows 或 Android 设备上，按以下顺序测试并记录结果。每一项都应以“新建 → 编辑 → 保存 → 关闭重开 → 导出”作为闭环，而不是只确认图标可点击。

| 场景 | 操作步骤 | 通过标准 |
|---|---|---|
| 真实压感 | 用不同压力缓慢书写同一支钢笔，再快速书写 | 状态栏显示真实压感来源；笔画粗细连续，无明显首点突变 |
| 掌托拒绝 | 触控笔书写时将手掌放在屏幕上并移动 | 已开始的笔画不中断；手掌不产生第二笔，也不触发缩放 |
| 双指缩放安全回退 | 落笔后立刻用第二根手指开始缩放或旋转 | 首个短笔画被取消，画布缩放/旋转正常，撤销栈不多出误触条目 |
| 高亮笔 | 选择任意颜色高亮笔，反复交叉涂写并在其上写字 | 交叠区域不持续加深变脏；文字或钢笔始终位于高亮笔之上 |
| 独立预设 | 分别设置钢笔、铅笔、高亮笔、橡皮擦的颜色/尺寸，循环切换并重启应用 | 每个工具恢复自己的参数；高亮笔颜色不再被硬编码为黄色 |
| 长笔划性能 | 以高采样率连续书写至少 30 秒，包含快速小字与慢速大字 | 跟手稳定，无持续掉帧；收笔后笔迹不跳变，保存与重开形状一致 |
| 导出闭环 | 保存笔记后重开，再导出 PNG、SVG、PDF | 三种导出均包含高亮笔、钢笔和铅笔，几何与颜色与编辑器一致 |
