## 二、真实功能闭环

### 2.1 连续粗笔与压感书写

笔画仍保存原始坐标与压感样本；渲染阶段才将样本转换为轮廓。这保证编辑、撤销、保存与重开不依赖临时位图。钢笔使用真实压力，铅笔使用较柔和的压力系数，高亮笔与橡皮擦保持固定宽度。活动笔画采用未完成轮廓减少高频输入抖动，收笔后重新生成完整轮廓以精确落在末端。[1]

### 2.2 形状工具

矩形、椭圆、菱形、直线和箭头均已采用拖拽创建。点击空白处会创建一个默认大小的形状；向任意方向拖动会按真实外接框创建。对于直线和箭头，水平/垂直翻转被持久化，因此从右下向左上拖拽不会变成方向错误的线条。新形状会保存至分页笔记或独立绘图文档，后者已包含版本化 JSON 读写路径。

### 2.3 两类工作区

| 维度 | **无限画布绘图** | **分页笔记** |
|---|---|---|
| 创建入口 | 首页“无限画布” | 首页“笔记本”→“新建页面” |
| 空间模型 | 无页面边界、世界坐标可为负或超出初始尺寸 | 固定 A4 比例页面与纸张模板 |
| 主要内容 | 手写笔触、形状、关系图、自由布局 | 手写、文字、图片、页面化资料 |
| 渲染策略 | 当前可视区直接矢量绘制，不受固定离屏位图裁剪 | 图层位图缓存与纸张背景，优化常规笔记性能 |
| 导出 | PNG/PDF/SVG；PNG/PDF 自动围绕实际内容边界 | Word 兼容 RTF、结构化 A4 PDF、PNG/SVG/Markdown |

无限画布导出会联合计算可见图层笔画和独立形状的边界，然后对导出画布平移，避免远离原点的内容被固定尺寸裁掉。空画布仍导出适中的默认区域，避免产生无效的零尺寸文件。

### 2.4 分页笔记导出

Word 兼容导出使用 RTF：标题、文字顺序、粗体、斜体、下划线、删除线、待办状态、便利贴高亮和中文 Unicode 均被编码为可编辑文档流。PDF 文字页嵌入随应用发布的离线 CJK 字体，因此 Windows 与 Android 不依赖设备字体或网络；若页面存在手写笔画，导出 PDF 会同时附加一页保真墨迹图像。

> 目前 Word 兼容导出针对**结构化文字内容**；手写、图片与形状的版面保真应使用 PDF、PNG 或 SVG。该限制已在界面行为和本记录中明确，不将“文本导出”伪装为完整版面 DOCX。

自动化测试保证了模型、序列化、几何、生成文件与引擎行为；以下体验项须在实体设备进行最终签收。

| 平台 | 操作 | 预期结果 |
