# 混合对象多选与组变换验收记录

**日期：** 2026-08-14  
**作者：** Manus AI  
**实施范围：** 独立绘图文档中的笔画、形状、图片混合选择与组变换；绑定箭头关系保持；锁定、取消、撤销/重做与持久化前安全边界。

## 验收结论

本轮已完成独立绘图文档的**混合对象多选与组变换真实闭环**。用户可以使用已有矩形选区或套索一次选中当前图层笔画、独立形状和离线图片；画布会展示统一组包围盒、四角手柄及锁定提示。多选集合可以整体移动或等比缩放，选中目标节点的绑定箭头会按锚点自动重投影，选中箭头的自由端会随组变换保持连续。

实现没有把多选停留在 UI ID 集合。变换过程以图层笔画、形状关系图和图片集合的深度快照组成**单一原子事务**；手势结束只压入一条撤销记录，取消严格恢复手势前快照，撤销/重做不会出现节点、连接线、笔画和图片分别回退的中间状态。

> **产品闭环：** 框选/套索 → 可见组边框 → 组移动或缩放 → 锁定保护 → 取消 → 一步撤销/重做 → 保存恢复。所有路径都通过真实控制器数据和自动化回归验证。

| 用户能力 | 已实现行为 | 关系与历史保证 |
|---|---|---|
| 混合框选/套索 | 选择笔画、形状和图片；矩形与任意套索多边形均支持对象相交命中。 | 形状/图片使用持久 ID，笔画使用当前图层索引；运行时选择不写入文档。 |
| 统一组包围盒 | 对所有选中对象计算可见 bounds，显示蓝色边框和四角手柄。 | 箭头 bounds 使用绑定投影视图，显示与命中保持一致。 |
| 组移动 | 同时移动未锁笔画、形状、图片与箭头自由端。 | 绑定端由归一化锚点随目标节点重投影。 |
| 组缩放 | 围绕真实混合包围盒中心等比缩放。 | 图片/形状遵守最小最大尺寸；绑定端优先保持关系。 |
| 锁定保护 | 锁定形状/图片保持选中并以琥珀色提示，但不参与变换。 | 混合操作条可批量锁定/解锁；笔画不引入伪锁定字段。 |
| 批量删除 | 删除未锁对象；受删节点的箭头端点先冻结绝对位置再解绑。 | 不遗留悬挂目标 ID；撤销可恢复目标、箭头和绑定。 |
| 取消与历史 | 取消恢复完整起始快照；结束手势形成一条命令。 | 图层、形状和图片在一个 `DocumentObjectsSnapshotCommand` 中原子恢复。 |

## 架构实现

现有单形状和单图片变换各自拥有独立历史命令，不能表达同时移动笔画、图片和关系图节点的需求。本轮新增 `DocumentObjectsSnapshot` 与 `DocumentObjectsSnapshotCommand`，保存图层列表、形状集合和图片集合的独立副本。恢复入口统一重建图层缓存、修正已失效选择 ID 并刷新画布，从而使数据状态、关系状态和可见反馈一致。

| 模块 | 本轮改造 | 作用 |
|---|---|---|
| `drawing_controller.dart` | 新增混合选择集合、多边形对象命中、组包围盒、批量移动/缩放/锁定/删除、取消和快照恢复。 | 控制器成为唯一的真实编辑入口，UI 不持有独立的文档对象状态。 |
| `document_commands.dart` | 新增混合深度快照和原子命令。 | 将笔画缓存层、形状绑定关系和图片几何纳入一条撤销边界。 |
| `editor_page.dart` | 将独立画布的矩形/套索结算、拖动、缩放、锁定、删除和取消接入混合对象接口。 | 图标与手势均可真正执行，不存在仅显示按钮的伪功能。 |
| `canvas_painter.dart` | 新增混合组包围盒、手柄和锁定标识。 | 多选具有清晰、低延迟、仅运行时的视觉反馈。 |
| `mixed_document_object_editing_test.dart` | 新增 5 项混合对象控制器回归。 | 持续防止对象关系、锁定守卫和历史原子性回归。 |

## 绑定箭头规则

在混合变换中，绑定关系优先于自由几何。先变换可绑定节点，再处理选中箭头的自由端，最后重投影全体绑定箭头。这一顺序对应 Excalidraw 在对象缩放中将受影响连接元素与目标集合纳入同一变换事务的思想，但实现为本项目独立的 Flutter/Dart 逻辑。[1]

| 选择状态 | 变换后的结果 |
|---|---|
| 仅选节点 | 箭头绑定端按锚点随节点移动/缩放。 |
| 选节点和箭头 | 绑定端随节点；自由端随整个选择组变换。 |
| 仅选自由箭头 | 两端按组变换。 |
| 仅选已绑定箭头 | 绑定端保持目标关系；本轮不隐式解绑。 |
| 选锁定节点/图片 | 锁定对象保持原位，未锁笔画与对象可继续参与变换。 |
| 删除目标节点 | 对应箭头端先冻结为绝对坐标、解除绑定；撤销完整恢复关系。 |

## 实施边界与下一阶段

本轮只实现单页、当前图层笔画的混合选择，不实现跨图层笔画选择、旋转、持久化分组、对象复制粘贴或箭头端点直接拖拽。这些能力都需要各自完整的数据模型、撤销语义和交互规格，不能以多选名义半实现。

下一阶段应优先实现**持久化分组与对齐/分布**，随后实现**箭头端点直接编辑**。前者让多选对象在反复布局中保持结构，后者让关系图具备专业的连线修订能力。二者完成后再推进文本容器，以形成流程图、结构化笔记与白板三种高频场景的统一对象编辑体系。
